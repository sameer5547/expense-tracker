Expense Tracker

A simple Expense Tracker built with Python. It has both a command-line interface (CLI) and a Flask web interface.

 Features

- Add expenses
- View expenses
- Calculate total spending
- Find highest expense
- Filter expenses by category
- Search expenses
- Filter by date
- Sort by amount
- Sort by date
- Edit expenses
- Delete expenses
- Input validation
